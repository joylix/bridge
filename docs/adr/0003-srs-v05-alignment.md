# ADR-0003：SRS V0.5 与已确认决策的一致性修订

- 状态：已接受
- 日期：2026-10-27
- 决策人：产品 / 开发
- 关联：`docs/桥牌软件需求规格说明书 V0.5.txt`、`docs/桥牌软件需求评审与开发建议.md` 0.4–0.6 与第 3 章、`docs/adr/0001-account-naming-retention.md`、`docs/adr/0002-brules-v05-phase0.md`、`docs/brules-v0.5/`

## 背景

SRS V0.5 已吸收注册制、命名规则与 1 年留存，但仍保留若干与已确认 P0 裁决、ADR 和 BRULES v0.5 设计不一致的表述。直接按 V0.5 开发会在数据模型、计分、AI 默认体系、裁判改分和转播隔离上产生返工。

本 ADR 只解决“已确认内容与 SRS 正文不一致”的问题，不新增产品范围，也不改变 BRULES Phase 3 已接受的 5M5332 行为修正。

## 裁决

| # | 不一致点 | 已确认口径 | 修订 |
| --- | --- | --- | --- |
| D1 | 数据模型 | 评审 P0-1：`Deal → TableBoard → SessionBoard`，`Board` 不再作为“牌型 + 某桌执行”的混合实体 | SRS 第 0 章与相关章节改用三层模型；`Board` 仅保留为 UI 文案 |
| D2 | MP / VP | 评审 P0-4：V1 删除 MP/VP，只保留合约分 + 队式 IMP；未来双人赛/VP 赛制单独立项 | SRS 1.2、3.1、6.8.4、7.1–7.4、10、11 同步；格式字段保留但不填充 |
| D3 | 室主改分 | 评审 P0-5：正式/队式赛改分收归管理员；室主仅可在练习房改分 | SRS 2.2、7.2.2、8.2 同步 |
| D4 | 默认叫牌体系 | 评审 P0-12 A + ADR-0002 D-10：体系可配置，默认精确制；自然制为可选模板 | SRS 6.4.3 同步；补充难度档位与 P95 预算 |
| D5 | 队式赛重新发牌 | 评审 P0-3：同一 `Deal` 的所有 `TableBoard` 必须一起重发，否则只能取消/调整分 | SRS 6.8.1 同步 |
| D6 | 裁判取消/调整分 | 评审 P0-11 原口径：取消记 0/0 原始分、0 IMP、`adjusted`；调整分落 `TableBoard` 原始分并重算 `SessionBoard`。**2026-10-28 由 ADR-0008 修订**：取消副改为 `rawScore=null`、`imp=null`，赛制补偿单独存 `artificialAverage`；调整分保留 `adjustment/adjustHistory` | SRS V0.7 6.8.1、6.11、5.5 同步；详见 ADR-0008 |

| D9 | 举手超时 | 评审 4.2 #6：避免“落座即自动踢”；改为室主点击【开始准备】后计时，未点击前只提示 | SRS 3.4、4.3.2 同步 |

| D11 | “一次设计完成” | 评审 4.2 #1：数据模型/接口一次做对，功能分阶段交付 | SRS 1.3.1 同步 |
| D12 | 性能指标 | 评审 4.2 #13：拆分网络广播 P95 与 AI 决策 P95 | SRS 9.1 同步；补充 DDS 回退要求 |

## 后果

- SRS 升为 **V0.5.1 一致性修订稿**，文件名保持不变，正文标注修订范围。
- `docs/brules-v0.5/srs-board-model.md` 从“建议稿”改为“已并入 SRS”。
- BRULES README、提案 v2 的待决事项同步 MP/VP、默认体系、转播延迟的最终口径。
- `src/engine/matcher.ts` 的 forcing new suit 判定改为 tags 优先；无 tags 时回退 id 前缀，保证旧手写规则兼容。
- 不改变 Phase 3 已接受的 `BAL_NO_5M` / `balanced:false` 两处语义修正，也不改变固定种子回归结论。
- 不把服务端、账号、跨桌聚合等 Profile P 能力误认为当前仓库已实现；它们仍是开发目标。

## 未决

- MP/VP 未来是否随双人赛/VP 赛制恢复，需单独立项，不在 V1。
- 转播延迟的具体数值仍可由系统管理员在 30 秒/延迟一副之间配置，但不得回到“无延迟、可控”的模糊表述。
- 独立裁判账号、邮件自助找回、固定牌型导入仍按 SRS 第 10 章后续处理。
