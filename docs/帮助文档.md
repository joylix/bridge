# 帮助文档

本文件说明游戏中的“计点/贴点制”与“叫牌、打牌规则浏览与修改”功能。

---

## 一、计点与贴点制

### 1. 标准计点（IMP）

每一副牌先按标准复式计分得到分数差（南北分 − 东西分），再按 WBF 标准表换算为
带符号的 **IMP（点数）**：正数表示南北赢，负数表示东西赢。

### 2. 贴点制

“贴点制”在标准 IMP 基础上，再按双方大牌点（HCP，A=4 / K=3 / Q=2 / J=1，全副 40 点）
做公平性修正。启用后，本副最终点数为：

```
本副点数 = IMP −（胜方联手大牌点 − 20）
```

- **胜方**：本副得分方——定约方成约时为定约方，宕墩时为防守方。
- 因为全副共 40 点，`胜方大牌点 − 20` 等于**双方大牌点差的一半**。
- 结果**可以为负**：拿高牌的一方若只赢到很少的 IMP，会被倒扣，从而鼓励低点进局、进贯。
- **流局（四家 Pass）**：没有得分方，改由大牌点多的一方贴点给少的一方，
  即 `本副点数 = 20 − 南北大牌点`。大牌点多的一方计负、少的一方计正；双方各 20 点记 0。

示例：

| 情况 | 分数 | IMP | 双方大牌点 | 贴点 | 本副点数 |
|------|------|-----|------------|------|----------|
| 南北 26 点做成 3NT | NS +400 | NS +9 | 26 : 14 | 6 | NS +3 |
| 南北 34 点仅成局 | NS +420 | NS +9 | 34 : 6 | 14 | NS −5（东西 +5） |
| 东西 12 点赢 3 IMP | EW +100 | EW +3 | 28 : 12 | −8 | EW +11 |
| 四家 Pass（流局） | 0 : 0 | 0 | 26 : 14 | 6 | NS −6（东西 +6） |

### 3. 循环与胜负

逐副折算后的点数按循环长度（默认 8 副，可切换 16 副）累加：

- **NS 累计点数 / EW 累计点数**：本循环内双方各自净得点数；
- **总点数差（计点胜负）**：`NS 累计 − EW 累计`，即当前循环的胜负。

计分面板（右侧“计点”区域）默认开启“贴点制”，并展示：

- 本局双方大牌点；
- 本局原始 IMP（未贴点）；
- 贴点调整量；
- 贴点后的本局点数、累计点数与总点数差。

取消勾选“贴点制”即可切换为纯 IMP 统计。贴点所需的双方大牌点会随对局一起归档，
因此切换开关后，历史对局与累计点数会立即按新口径重算。

结果窗口与详细结果中，标为 **“NS/EW 原始分”** 的列是复式赛原始得分（未贴点）；
标为 **“NS/EW 点数”** 或 **“本局点数（已贴点）”** 的列才是贴点制折算后的最终点数。

## 二、叫牌规则与打牌规则的浏览、修改

### 1. 入口

点击页面顶部工具栏的 **“规则管理”** 按钮，打开“叫牌 / 打牌规则”窗口。

### 2. 三个页签

- **叫牌规则**：对应 `src/rules/bidding/*.yml`（默认 `precision`，备选 `natural`）。
- **打牌规则（首攻）**：对应 `src/rules/play/leads*.yml`，由 YAML 规则驱动。
- **打牌细则（跟牌/垫牌）**：对应 `src/rules/play/signals*.yml`，列出第二/三/四家跟牌、
  张数信号、无将/有将垫牌与避免堵塞等约定；其中 `settings` 的两个阈值由程序直接读取并改变行为。

### 3. 打牌约定细则

当前版本实现以下防守约定：

| 场景 | 约定 |
|------|------|
| 第二家跟牌 | 通常出小牌；对手领出 10 以上的荣誉大牌时，用**最小能盖过它的牌**盖打；同伴领出的荣誉大牌不盖 |
| 第三家跟牌 | 同伴的荣誉大牌已赢则出小牌；同伴的小牌当前虽赢但可能被第四家超过时，出**最小能赢的牌**保护；对手当前赢时同样用最小赢张（连张时保留更大牌） |
| 第四家跟牌 | 能赢则用**最小赢张**；同伴（第二家）已经赢墩时不得无谓超打同伴 |
| 跟牌（张数信号） | 该花色剩**偶数张**时“先大后小”，剩**奇数张**时“先小后大”；信号张只用 10 及以下，保留 J 以上大牌 |
| 对方 NT 定约 · 首攻（仅防守方） | 手中**没有长套**（四门均 ≤4 张）时，首攻**敌方未叫过的高级花色**（长四）；有 5+ 张长套时首攻长套。默认取**第 4 张**；若长套顶张为 AKQ/KQJ/QJT/JT9 等连张，则改出**连张顶张** |
| 垫牌 · 无将 | 从**不鼓励（荣誉力量最弱）**的花色垫最小牌。若已知同伴长套，优先避开；只能垫该花色时**保留低牌、改垫最小荣誉牌**，避免堵塞桥引 |
| 垫牌 · 有将（无损失鼓励） | 若某非将花色有力量且存在无损失的高信号张（8/9/10），垫该张表示**鼓励同伴攻此花色**；不从同伴长套垫。没有则回退为“最弱花色垫最小牌” |

同伴长套的判定：明手可见时，读取明手 5+ 张且有荣誉的花色；否则参考同伴在叫牌中叫过的花色（1♣/1♦ 在精确制中可能是短套或虚叫，不单独作为长套）。

### 4. 浏览细则

- 在文件下拉框中选择要查看的规则文件；
- “浏览细则”以表格展示每条规则的：
  - 叫牌：`id`、说明、`sequence`（相对座位序列）、`when`（手牌条件）、`action`（叫品）、`priority`；
  - 首攻：`id`、说明、`contract_type`（NT / 有将）、`role`（适用方：防守方 / 庄家侧 / 不限）、`when`、`lead`（首攻策略）、`priority`；
  - 跟牌/垫牌：`id`、说明、`phase`（跟牌 / 垫牌 / 信号）、`when`、`action`（策略）、`priority`，
    并显示 `settings` 中当前生效的可执行阈值。
- 表格按 `priority` 从高到低排列，与 AI 的裁决顺序一致。
- 叫牌条件中的 `openingSeat` 表示开叫座位：`1`=发牌人，`2`=第二家，`3`=第三家，`4`=第四家；
  仅用于首叫（开叫）规则。

### 5. 修改细则

1. 点击“编辑源码”，进入 YAML 编辑模式；
2. 修改规则文本（可改条件、动作、优先级，也可新增/删除规则）；
3. 点击“保存并应用”：
   - 先做语法与基本字段校验，失败时展示具体错误，不会写入；
   - 校验通过后保存到浏览器本地（`localStorage`），并立即应用到 AI；
4. 点击“恢复默认”可清除本地修改，回到内置 YAML。

若当前浏览的文件不是 AI 正在使用的文件，可点击 **“设为当前使用”** 切换激活文件。
规则修改保存在本机浏览器中，刷新页面后仍然有效；不同浏览器/设备之间不共享。

> 提示：修改 `action` / `lead` 时请使用规则文件中已有的取值，或确认程序支持的新取值，
> 否则该条规则可能无法产生预期动作。

### 6. 权限说明

- **当前阶段**：所有用户都可以浏览并修改规则（编辑、保存、恢复默认均可用）。
- **后续阶段**：接入账号/后台后，将改为**仅系统管理员可修改**，普通用户只读。
  权限策略集中在 `src/permissions.ts` 的 `RULES_ADMIN_ONLY` 开关：
  - `false`（当前）：所有用户可编辑；
  - `true`：仅 `admin` 角色可编辑，普通用户打开规则窗口时只读。

## 三、叫牌含义、推荐叫品与推荐出牌

### 1. 叫牌含义浮层

- 叫牌阶段只有一个浅青薄纱文字浮层，背景不透明度约 40%，默认不显示；
- 浮层位于中央叫牌记录右侧，只轻微压住记录区右边，不再遮挡整张叫牌表；
- 鼠标悬停到中央叫牌表中任意已完成的叫品时，浮层显示该叫品的规则含义，移开记录格后立即隐去；
- 浮层无边框、无题头；
- 叫牌结束（进入打牌/结算）后不会再显示。

### 2. 推荐叫品

- 轮到人类叫牌时，规则引擎按优先级选出最高候选，自动选中该叫品，推荐格子用绿色高亮；
- 直接点“确认”即可打出推荐叫品；
- 鼠标悬停任意合法叫品时，中央浮层显示该叫品含义，并附带推荐叫品及其含义；
- 叫牌卡内不再保留独立推荐说明区，也不需要“恢复推荐”按钮；如果改选了其他叫品，直接点击绿色推荐格即可回到推荐叫品；
- 推荐只使用规则库中的候选与合法性过滤，不会替人类自动提交。

### 3. 推荐出牌

- 轮到人类出牌且有多张合法牌时，原来的闪烁回合箭头会移动到推荐牌上，推荐牌本身不再自动弹起；
- 箭头仍然表示“轮到你出牌”；悬停箭头会显示推荐理由，键盘聚焦箭头也可以查看；
- 非人类回合、关闭提示或没有推荐时，箭头回到手牌固定中间位置，只指示该座位出牌；
- 人类坐庄操作明手时，箭头同样会指向明手手牌中的推荐牌；
- 推荐牌不改变选牌状态：左键可以自由选中/取消，右键直接出牌；只有被左键选中的牌会弹起；
- 推荐理由来自已固化的首攻规则 + 跟牌/垫牌启发式，例如“第四家用最小赢张”“缺门，用将牌将吃”等；
- 唯一合法牌会直接自动打出，不再显示推荐；
- 每轮四家出牌完成后，中央桌面会完整保留该墩 4 张牌约 1 秒，再切换到下一墩；
- 推荐使用同步启发式，不调用耗时的 DDS，保证即时响应。

### 4. 关闭提示

顶部“风格 / 规则设置”中的 **“显示提示与推荐（叫牌含义 / 推荐叫品 / 推荐出牌）”** 可一键关闭：

- 不再自动选中推荐叫品、不显示推荐高亮；
- 不再显示叫牌含义浮层与推荐含义；
- 不再把箭头移到推荐牌，也不再显示推荐理由；固定位置的回合箭头仍然保留。

该设置保存在本机浏览器（`localStorage`），刷新后保留。

## 四、双明手分析（DDS）

### 1. 入口

- 一局结束后打开**详细结果**弹窗，最下方有“双明手分析”折叠栏，点击后才展开并开始计算；
- 详细结果按“结果信息 → 牌型分布 / 叫牌过程 → 打牌过程 → 双明手分析”的顺序排列，
  打牌过程使用固定高度，更多墩数在面板内滚动查看；
- 或在**结果窗口**右上角点击 **“双明手”**，查看当前展示牌局的分析。

### 2. 结果说明

- **结果表**：行为将牌（♠ ♥ ♦ ♣ NT），列为庄家（N/E/S/W），格子中的数字为该庄家在该将牌下可赢的墩数；
  - 绿色：≥ 7 墩，表示可以成约；
  - 金色描边：本副实际定约对应的格子。
- **Par 定约**：双方都按最优攻防时的理论最佳结果，分数以 NS 视角显示（负数表示 EW 得分）。
- **可成约定约**：列出各花色能达到 7 墩以上的定约、庄家与墩数。

### 3. 机器人深度打牌

设置中可开关 **“DDS 深度打牌（隐藏牌抽样）”**，默认开启：

- 机器人只使用自己的手牌、已摊开的明手、已经打出的牌和各座位剩余张数；
- 未知牌按剩余张数随机分配，并用叫牌过程做宽松的大牌点下界过滤；
- 每个分布交给 DDS 求最佳出牌，再按多个样本的投票选择；
- Worker 不可用、超时或样本非法时自动回退到原启发式，不影响对局；
- **不会读取其他三家的真实手牌**，因此不是双明手作弊。

> 注意：上方“双明手分析”区块仍然使用完整四手牌，仅用于复盘；它与机器人实战出牌是两条独立路径。

### 4. PBN 导入 / 导出

牌桌顶部 **“PBN 导入/导出”** 可以：

- 读取当前牌局并生成标准 PBN 字符串（打牌过程中也使用开局快照）；
- 复制到剪贴板、下载 `.pbn` 文件；
- 粘贴合法 PBN 后作为新一局开始叫牌，发牌人取 PBN 前缀。

### 5. 注意事项

- 双明手分析假设**四家牌全部明牌**，并采用最优攻防，因此只适合复盘参考，不代表实际对局结果；
- 分析由浏览器本地 WASM（DDS）在后台 Worker 中完成，不会上传牌局；
- 首次分析需要加载求解器，可能需要短暂等待；若浏览器不支持 Web Worker 或求解超时，会显示提示，不影响正常计分和复盘。

## 五、窗口拖动

- **详细结果**、**PBN 导入/导出**、**计分表结果**窗口可直接拖动标题栏移动；
- 拖动后松手、或误点窗口外的暗色遮罩，**不会关闭窗口**，避免拖动时意外退出；
- 关闭窗口请使用右上角 **×**、底部的 **关闭** 按钮，或按 **Esc**。
- 叫牌浮窗的标题栏标有“拖动移动”，拖动时只移动位置，不会提交叫牌。
